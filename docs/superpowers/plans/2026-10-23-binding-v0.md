# Binding v0 Implementation Plan

> For agentic workers: use executing-plans inline, following the durable root
> CHECKLIST.md and HANDOFF.md. Do not repeat completed checkpoints.

**Goal:** Reproducible learned one-bit relation transfer with bounded CPU cost.
**Architecture:** Exact finite dataset; two tiny networks communicate through a
binary channel. A runner checkpoints complete seeds and rejects mixed runs.
**Tech Stack:** Python 3.10+, NumPy, unittest.
**Spec:** ../specs/2026-10-23-binding-v0-design.md and root PREREG.md.

## Global constraints
Five fixed seeds; 5000 steps; exact hard-message evaluation; no product features
to learners; preserve negative results; no GPU/model download; no tuning on v0.

## Review focus
No source labels entering receiver features; no floating-probability side channel;
no overlap in combinatorial split; no stale checkpoints accepted; no claim of
zero-shot transfer from supervised fresh-reader training.

### Task 1: instrument and learners
Files: binding.py, tests/test_binding.py, requirements.txt.
Interface: dataset() returns source, query, labels, worlds, train mask;
MLP exposes forward/backward, joint_loss_grad returns objective and gradients;
run_seed(seed, steps, lr) returns JSON-safe metrics/cases plus weights.
- [ ] Write tests for 32/24/8 coverage, balanced receiver labels and world marginals,
  hand-checked oracle fixtures, gradients against central finite differences.
- [ ] Run unittest; confirm missing implementation failures.
- [ ] Implement data, exact discrete expected loss, Adam and controls.
- [ ] Run tests; require all pass. Commit the tested instrument.

### Task 2: resume and bounded batch
Files: run.py, tests/test_run.py, results/v0/*, RESULTS.md.

one JSON/NPZ per seed, and aggregate summary; returns summary.
- [ ] Write tests for partial run/resume, config mismatch, corrupt cache and
