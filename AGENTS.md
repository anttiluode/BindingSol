# BindingSol continuity rules

Read README.md, CHECKLIST.md, HANDOFF.md and PREREG.md before changing code.
Resume the first unchecked item; inspect git history and saved results first.
Every checkpoint must include the current status, exact command to continue,
measured evidence, and unresolved issues. Keep these documents in git.

This is the Sol-owned workspace. Do not edit other repositories. Keep CPU-only
defaults, short reproducible batches and explicit stopping rules. Do not launch
large models, multi-agent implementation teams or parameter sweeps by default.

Preserve registered failures. No tuning on held-out results. Version new protocols
before running changed experiments. Distinguish hard discrete communication from
probability leakage, supervised adaptation from zero-shot transfer, and finite
symbolic completion from image modelling. Never claim neuroscience/novelty from
this toy. Run the full test suite before claiming completion.
